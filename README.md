# DecisionJudge

DecisionJudge 是一款面向个人重大决策的本地 Web 工具。它用评价维度、权重、机会成本和沉没成本，帮助你把“我不知道怎么选”整理成一份可解释、可复查的比较。

当前版本是本地自用 MVP：不需要账号，不把决策数据发送到云端，数据保存在浏览器 IndexedDB 中。内置模板包括：

- 升学还是就业
- 换工作
- 选择城市
- 重大消费或购房

## 本地运行

```bash
pnpm install
pnpm dev
```

然后打开终端输出的本地地址。生产构建和测试：

```bash
pnpm build
pnpm test
```

## 使用方式

从模板创建一项决策，确认方案和权重，为每个方案在每个维度上打 1-10 分，然后查看排序、机会成本、净优势和结论稳定性。高级模式可以展开专业微调入口；每个高级模块独立启用，折叠界面不会悄悄改变结果。

本地记录支持导入和导出 JSON 备份。清理浏览器数据可能导致本地决策丢失，请定期导出备份。

## 项目结构

- `src/domain`：纯计算规则、类型和决策模板
- `src/application`：创建、评估、快照和导出用例
- `src/infrastructure`：IndexedDB 本地仓储
- `src/App.tsx`：响应式 Web 界面
- `docs`：需求、架构、数据模型和应用契约
