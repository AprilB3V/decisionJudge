# DecisionJudge

DecisionJudge 是一款面向个人重大决策的本地 Web 工具。它把方案比较、关键假设验证、投入记录、行动计划与复盘连成完整流程，让选择有依据，也能在事后检验。

当前版本为 0.3.0：不需要账号，决策记录保存在浏览器 IndexedDB 中。手动启用问答助手时，会将当前比较结构和本轮对话发给你配置的模型服务。内置模板包括：

- 升学还是就业
- 换工作
- 选择城市
- 重大消费或购房
- 空白模板，也可将自己的方案、维度、锚点和权重保存为预设

## 本地运行

使用 Node.js 22.18.0 和 pnpm 11.19.0（版本已在 `package.json` 中声明）。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

然后打开终端输出的本地地址。生产构建和测试：

```bash
pnpm build
pnpm test
```

## 使用方式

1. **比较方案**：普通模式只需设置权重、填写评分和备注；权重可按比例调整到 100%。切换专业模式可编辑评分锚点、使用摆幅赋权并填写证据类型、信心、日期和来源。两种模式使用同一套数据，切换不丢细节。结果显示条件排名、并列、相对贡献和权重敏感性；只有已核实满足全部底线的方案才能确认并封存快照。
2. **验证与投入**：把可能改变选择的未知写成验证任务，记录方法与发现。分别记录人民币、小时和可回收金额；达到承受边界时提示复评，不自动改变排名。
3. **行动与复盘**：写下“如果—那么”计划与障碍应对；在截止日期前封存二元预测，截止日结束后记录结果并计算 Brier 平均平方误差。复盘区分别记录判断、执行、外部变化和下一步；复盘草稿自动保存，追加后的记录不可改写。

## 通过问答完成首轮设计

在任一决策中点击 **“问答梳理 · 帮我开始”**，展开 **“API 与提示词设置”**：

1. 填入兼容 OpenAI Chat Completions 的基础地址（例如 `https://服务地址/v1`，或完整 `/chat/completions` 地址）、模型名称和 API 密钥。本机无鉴权模型服务可留空密钥。
2. 选择“通用决策教练”“职业与学习”或“消费与生活选择”提示词，可展开编辑并保存。地址、模型和提示词保存在本机；密钥只在页面内存，刷新后需重新填写。
3. 描述正在面对的选择，助手按一轮一个主要问题引导你澄清目标、方案、底线与偏好。想先看结构时点击“整理首轮草稿”。
4. 预览建议后勾选替换说明，点击“应用草稿，检查权重”。应用会重建当前方案、维度和底线，清空评分；执行历史和历史快照保留。权重可修改，分数由你填写，底线状态仍需核实。

问答只发送当前问题、方案/维度及备注、底线和本轮聊天，不发送评分证据或执行历史。聊天在离开编辑器或刷新后清除。服务需支持浏览器 CORS；不支持时可配置允许跨域的兼容网关。请求支持停止、60 秒超时与失败重试。程序不内置密钥，也不会自动访问模型服务。

当前数值模型为确定性加权比较（`weighted-utility-v2`），比较分不是概率。敏感性检查对各正权重做 ±5 个百分点的局部扰动，并按比例调整其余权重；它不表示所有不确定性下的稳健性。情景概率、风险偏好、因素层次和折现等高级数值模块尚未参与计算。

内容自动保存，返回列表前会等待最近输入写入。多个页面同时修改同一决策时会提示冲突并保留当前输入，可导出当前草稿后重新打开。快照保存当时的输入与结果；修改比较条件会重新回到草稿，历史快照仍保留。

本地记录支持 JSON 备份，兼容没有工作流字段的旧记录。导入前验证结构、引用与工作流规则；遇到 ID 冲突会作为新记录导入，并同步调整快照归属，不覆盖原记录。清理浏览器数据可能导致本地决策丢失，请定期导出备份。

## 项目结构

- `src/domain`：纯计算规则、类型和决策模板
- `src/application`：创建、评估、快照、串行保存会话与备份校验
- `src/infrastructure`：IndexedDB 本地仓储
- `src/components`：五步比较、验证与投入、行动与复盘界面
- `src/App.tsx`：本地记录、导航与导入导出编排
- `docs`：需求、架构、数据模型和应用契约
